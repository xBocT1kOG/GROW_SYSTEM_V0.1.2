# Отчёт о непрерывном тестировании V0.2

Этот каталог содержит только производные результаты анализа. Исходный журнал:
`PC_collector/2026-11-06_01-30.csv`. Анализируется именно этот файл, а не
одноимённый рабочий журнал в `PC_collector/LOGS/`.

## Состав

- `endurance-report-ru.md`: редактируемый текст отчёта.
- `GROW_SYSTEM_V0.2_Endurance_Test_Report_RU.pdf`: итоговый A4 PDF.
- `summary.json`: рассчитанные показатели, начальные/конечные значения и приросты,
  окна обнаружения ошибок, переходы автоматики, SHA-256 исходного CSV.
- `assets/`: четыре графика и сводная схема в PNG и редактируемом векторном SVG.
- `analyze_endurance.py`: полный анализ без изменения, сортировки и очистки CSV.
- `write_report.py`: генерация Markdown из summary; рассчитанные показатели
  подставляются автоматически. Защитные проверки останавливают генерацию,
  если другой журнал уже не соответствует выводам этого отчёта.
- `build_pdf.py`: сборка PDF из редактируемого Markdown.
- `verify_analysis.py`: независимый пересчёт ключевых показателей и проверка PDF.

## Воспроизведение

Python 3.11+; для анализа нужны numpy и matplotlib, для PDF - reportlab и Pillow,
для проверки PDF - pypdf и pdfplumber. Для рендеринга страниц используется Poppler.
Arial и Consolas берутся из установленной ОС; файлы шрифтов не включены.

```text
python docs/test-report/analyze_endurance.py
python docs/test-report/write_report.py
python docs/test-report/build_pdf.py --font-dir C:/Windows/Fonts
python docs/test-report/verify_analysis.py
pdftoppm -r 110 -png docs/test-report/GROW_SYSTEM_V0.2_Endurance_Test_Report_RU.pdf <private-preview-prefix>
```

При отдельных средах Python анализ и сборка PDF могут запускаться разными
интерпретаторами с соответствующими зависимостями. В проектном окружении графики
создавались matplotlib 3.11.2 / numpy 2.4.6, PDF - ReportLab из bundled runtime.
Повторная генерация текста перезапишет ручные правки Markdown; после ручной
редактуры запускайте только `build_pdf.py` и проверки.

## Методические оговорки

- Интервал считается по timestamp_epoch с миллисекундами. Время на графиках
  соответствует UTC offset исходного CSV (+02:00), а не настройкам машины анализа.
- Накопительные метрики: начало, конец, min/max, прирост, число уменьшений и
  окна наблюдения прироста критических счётчиков. Среднее счётчиков не считается.
- Итог коллектора включает первую строку: 1 → 7180 означает 7180 полных опросов,
  а не 7179. Прирост счётчиков устройства относится только к интервалу между
  первым и последним снимками.
- Порог заметного интервала >15 с - правило анализа, не норматив системы.
- Успешные /api/state и /api/diagnostics - последовательные, не атомарные ответы.
- valid=True означает сохранённое валидное значение и не исключает ошибок между
  опросами. Три ultrasonic_errors и три ultrasonic_timeouts - одни события.
- Wi-Fi=1 с нулевым приростом не доказывает восстановление связи во время теста.
- Нет метрик точности датчиков, агрономических выводов или сравнения с коммерческими
  системами. Нет утверждения о доказанном отсутствии любых утечек памяти.
- CSV не идентифицирует прошитый бинарный файл. Хеш исходной ревизии в отчёте -
  контекст проверки реализации, а не доказательство версии работающего устройства.

## Проверка результата

Все строки обработаны, основные расчёты независимо перепроверены. Проверяются
hash исходного CSV, счётчики, интервалы, heap, стеки и отсутствие обрезанных
символов за полями PDF. Каждая страница дополнительно просматривается после
рендеринга: программная проверка текста не заменяет визуальную.
Временные изображения страниц и локальные контрольные хеши хранятся вне этого
каталога, в игнорируемом `.pio/endurance-report-build/`.

## Украинская и английская локализации

Канонический редакционный источник - `endurance-report-ru.md`. Переводы:
`endurance-report-uk.md` и `endurance-report-en.md`; соответствующие PDF имеют
суффиксы `_UK.pdf` и `_EN.pdf`. Во всех трёх версиях по 9 страниц, 8 разделов,
8 нумерованных таблиц (плюс оглавление) и 5 рисунков. Числа, выводы, ограничения
и ссылки на исходные материалы сохранены; в английском используется десятичная точка.

`localize_figures.py` заменяет только текстовые узлы готовых русских SVG.
CSV и `summary.json` не читаются и не пересчитываются. Все координаты, линии,
значения и остальные элементы SVG сохраняются. В `assets/` добавлены варианты
пяти рисунков с суффиксами `-uk` и `-en`, каждый в SVG и PNG.

Для воспроизведения локализации **не запускайте анализ или `write_report.py`**:

```text
python docs/test-report/localize_figures.py
node docs/test-report/render_localized_figures.cjs <node_modules> <browser.exe> <DejaVu-font-dir>
python docs/test-report/verify_localization.py
python docs/test-report/build_pdf.py --lang uk --font-dir C:/Windows/Fonts
python docs/test-report/build_pdf.py --lang en --font-dir C:/Windows/Fonts
```

Для растеризации используются Playwright и локальный Chromium/Edge, а также
установленные DejaVuSans.ttf и DejaVuSans-Bold.ttf (например, из matplotlib).
Шрифты загружаются только на время рендеринга и не включаются в SVG или репозиторий.
Разрешение PNG совпадает с русскими оригиналами. Без `--lang` сборщик PDF
по-прежнему выбирает русский Markdown; при локализации русский PDF не пересобирается.

`verify_localization.py` проверяет числа по абзацам и ячейкам таблиц, порядок
строк, технические идентификаторы/пути, число и нумерацию разделов/таблиц/рисунков,
перевод SVG-подписей, неизменность геометрии и размеры PNG. Проверка не заменяет
сопоставление смысла выводов и визуальный просмотр всех страниц трёх PDF.
При выпуске локализаций просмотрены 27 страниц; оглавления, поля, таблицы,
подписи и украинские символы і/ї/є/ґ проверены. Временные материалы проверки
расположены в игнорируемом `.pio/endurance-localization/`.
