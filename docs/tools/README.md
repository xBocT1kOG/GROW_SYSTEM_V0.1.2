# Повторное построение иллюстраций

Команды выполняются из корня репозитория. Инструменты только читают исходный CSV
и Markdown; результат записывается в `docs/assets/`. Прошивка и коллектор не меняются.
Исходные CSV остаются локальными, действующее правило исключения Git сохраняется.

## Графики и сводка CSV

Использованы Python 3.11 и Matplotlib 3.11.2. Пример отдельного окружения:

```powershell
python -m venv .pio/docs-venv
.pio/docs-venv/Scripts/python -m pip install matplotlib==3.11.2
.pio/docs-venv/Scripts/python -B -X utf8 docs/tools/generate_test_charts.py --source PC_collector/LOGS/2026-11-04_04-14.csv --max-rows 6584
```

Зафиксированы первые 6 584 строки данных, включая неуспешные запросы. Заголовок
не входит в это число. SHA-256 исходных байтов префикса, включая заголовок и окончания
строк: `e3e77e7cd28927ee705f7cc9cef39613613e8b2f9ab6af133cc7e4a40875740d`.
Дальнейший рост файла не меняет этот результат. Исходный CSV в репозитории отсутствует:
для воспроизведения нужен локальный файл с тем же префиксом. Переименование или
преобразование окончаний строк изменит сведения об источнике либо контрольную сумму.

Скрипт проверяет временные метки, флаги ответов и поля через валидатор коллектора.
Незавершённая последняя строка при чтении растущего файла исключается. Участок
разрывается при невалидном ответе, интервале более 25 секунд, нарушении порядка
времени или уменьшении uptime/накопительных счётчиков. Выбирается самый длинный
участок по времени; при равенстве — по числу записей. Нужны минимум две записи.

Ошибка датчика не делает корректный HTTP-снимок невалидным. Для графиков текущая
ошибка или отсутствие валидного значения даёт разрыв линии, а не ноль. LIGHT_S
отображается ступенями; остальные ряды соединяют исходные точки без сглаживания.
Сводка содержит как весь префикс, так и выбранный участок: ошибки за его пределами
не скрываются. Прирост счётчика вычисляется между крайними снимками участка.

Результат: два PNG и `preliminary-test-summary.json`. Для другого набора можно
передать `--source`, `--max-rows` и `--output`; текст обзора затем нужно сверить
с новой сводкой. Воспроизводимость пикселей требует одинаковых версий Matplotlib,
его зависимостей и шрифта DejaVu Sans. Автоматическая проверка правил отбора:

```powershell
python -B -m unittest discover -s docs/tools -p "test_*.py"
```

## Архитектурные схемы

Источником служат четыре блока Mermaid в `docs/device-overview-ru.md` в порядке:
аппаратная схема, архитектура задач, свет, диагностика. Скрипт проверяет каждый блок
через `mermaid.parse()`, затем создаёт SVG и PNG. Требуются Node.js, пакет Playwright,
локальный браузер Chromium/Edge и Mermaid 11.12.2. Например:

```powershell
npm install --prefix .pio/docs-render playwright@1.62.1
Invoke-WebRequest https://cdn.jsdelivr.net/npm/mermaid@11.12.2/dist/mermaid.min.js -OutFile .pio/docs-render/mermaid.min.js
$env:NODE_PATH = (Resolve-Path .pio/docs-render/node_modules).Path
node docs/tools/render_diagrams.cjs .pio/docs-render/mermaid.min.js 'C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe'
```

При установленном Playwright из другого окружения укажите соответствующий
`NODE_PATH`. Браузер запускается без окна; сетевых запросов при отрисовке нет.
Зафиксированы стиль, идентификаторы Mermaid и масштаб PNG. Версия браузера и
доступность Arial могут влиять на размеры надписей и пиксели: после обновления
инструментов изображения нужно открыть и проверить заново. SVG предпочтителен
для дальнейшей PDF-вёрстки. Итоговый PDF на этом этапе не создаётся.
